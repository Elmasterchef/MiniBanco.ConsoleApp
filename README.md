# MiniBanco.ConsoleApp

Mini-projeto avaliativo desenvolvido em C# e .NET 10.

## Objetivo

Simular operações e regras de contas bancárias utilizando programação orientada a objetos.

## Tecnologias

- C#
- .NET 10
- Git e GitHub
- Docker

## Status do projeto

Estrutura inicial criada. As regras bancárias serão implementadas nas próximas etapas.

## Executar localmente

Na raiz do repositório, execute:

```powershell
dotnet run --project "src/MiniBanco.ConsoleApp/MiniBanco.ConsoleApp.csproj"
```

## Testes

Os testes automatizados serão adicionados durante o desenvolvimento.

## Docker

As instruções de construção e execução serão adicionadas após a configuração e validação do Dockerfile.
